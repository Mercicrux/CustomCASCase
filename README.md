This is a custom case for the Ti-Nspire CX CAS I (not II). Here are some notes about the current build:
1. I am likely never going to make a full replacement for the case at this point, as I've mostly lost interest in this project. The latest version I've uploaded is probably the most complete I'll ever make it.
2. Whilst I know the battery cover is not compatible with the CX II, and the charging port cover might be (not sure), and the case 100% is.
3. For best looking case, try looking at the example 3mf file I've given, and try using multicolour filament, using different bottom layer patterns on the different pattern objects in the assembely. I've also uploaded a photo of the final results of the print in the example file, so it's easy to see how it works.

If you find this repository and want to make an actual case (not just the easy parts like the cover and battery backing) then the BackCase part in the .FCStd file is where you can start. It's got very little progress on it but its better than nothing.
